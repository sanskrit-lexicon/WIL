# WIL 1819 (first edition) — Front matter (prefaces)

_Created: 05-08-2026 · Last updated: 05-08-2026_

OCR transcription of the **front matter** (title page, dedication, preface, list of authorities, and the "Application of the Roman Character" table) of:

> **WIL 1819** — H. H. Wilson, *A Dictionary, Sanscrit and English*, **first edition**, Calcutta: printed by Philip Pereira, at the Hindoostanee Press, **1819**. Collation: [iv] + l + 1061 pp., 4°.

**⚠ Edition = 1819 first ed. — NOT the CDSL text.** The Cologne Digital Sanskrit Lexicon `wil` dictionary (and the front-matter OCR in the sibling [Wil-YAT repo](https://github.com/sanskrit-lexicon/Wil-YAT/tree/main/prefaces)) is the **1832 second edition**. This folder is the European-lineage complement: WIL **1819** is the print base of PWG and the head of the dictionary-tradition stream that MW marks `L.` — see [docs/WIL_EDITION_LINEAGE_1819_1832.md](https://github.com/sanskrit-lexicon/WIL/blob/main/docs/WIL_EDITION_LINEAGE_1819_1832.md).

- **Source scans:** [archive.org: wilson-a-dictionary-in-sanscrit-and-english-1819](https://archive.org/details/wilson-a-dictionary-in-sanscrit-and-english-1819) (Google Books digitisation of the Bayerische Staatsbibliothek copy, *Bibliotheca Regia Monacensis*; Public Domain Mark). Cologne csldoc has **no** 1819 scans — its WIL front matter is 1832.
- **Source language:** English. Because the source is already English, there is **no `.en.md`** per-page file; the source page *is* the English text.
- Full-resolution page images (~5169×7249 px) are fetched per leaf via IIIF: `https://iiif.archive.org/iiif/wilson-a-dictionary-in-sanscrit-and-english-1819$<leaf>/full/full/0/default.jpg`. The leaf ↔ page map is [_manifest.json](https://github.com/sanskrit-lexicon/WIL/blob/main/prefaces/_manifest.json).
- Original spelling preserved verbatim (*Sanscrit*, *synonimes*, *compleat*, …); Google digitizer watermarks and Munich library stamps are omitted. Leaf 7 (title verso) is blank apart from library stamps and is not transcribed.
